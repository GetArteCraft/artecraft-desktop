# Безопасность

## Что считается уязвимостью
- обход проверки источника загрузки (только `github.com` / `*.githubusercontent.com`);
- path traversal при распаковке zip/tar/deb;
- запуск команд без явного действия пользователя;
- утечка токена аккаунта или отпечатка устройства в логи/телеметрию;
- подмена ответа `/api/market/catalog` с исполнением кода.

## Как сообщить
Пишите на security@getartecraft.com (или в issue без деталей эксплуатации).
Ответ — в течение 72 часов. Публичное раскрытие — после исправления.

## Что известно и принято
- Бинарники не подписаны: SmartScreen/Gatekeeper предупреждают. Это не уязвимость.
- Пост-инсталл хук выполняет команду, которую ввёл пользователь. Это осознанная функция.
- Сторонние сборки из маркетплейса не проверяются антивирусом — в UI есть экран риска.
