# Маркетплейс

Серверная часть: `getartecraft.com` (`/api/market/*`). Лаунчер только читает каталог и отправляет действия.

## Как добавить приложение
1. Аккаунт ArteCraft (уникальный `@handle`, привязка к железу).
2. Marketplace → «+ Добавить свой репозиторий» → ссылка на GitHub.
3. Сервер проверяет репозиторий и релиз, запись уходит на модерацию.

## Один репозиторий = одна запись
Если репозиторий уже в каталоге, вы **присоединяетесь**: счётчик «добавили» растёт, дубля нет.
Список людей не публикуется — только число.

## Правки по пунктам
Кнопка «✎» на карточке открывает форму: выбрать поле (описание, ОС, категория, теги, название, лицензия),
вписать верное значение и пояснение. Одна правка = одно поле; модератор принимает или отклоняет **каждый пункт отдельно**.
Принятая правка сразу меняет запись, автор правки получает бейдж `contributor`.

## Пометки
- **проверено** — модерация подтвердила репозиторий и сборки;
- **официально от ArteCraft** — запись ведёт команда ArteCraft.

## Баны
Модератор может забанить аккаунт (с опциональным скрытием всех его приложений) или отдельную запись.
Причина бана видна пользователю при входе.
