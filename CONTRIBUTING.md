# Как участвовать

## Баг или идея
Откройте issue: что делали, что ожидали, что получили. Для UI — скриншот, для установки — название приложения и ОС.

## Pull request
1. `cd src && go vet ./... && go test ./...`
2. Один PR — одна тема. UI (`src/ui/index.html`) и Go (`src/*.go`) держите в отдельных PR, если это не одна фича.
3. Коммиты: `feat:`, `fix:`, `docs:`, `refactor:`, `chore:`.
4. В PR опишите, что проверяли руками (ОС, сценарий).

## Стиль кода
- Go: `gofmt`, без новых зависимостей без обоснования (сейчас только `go-webview2` и `golang.org/x/sys`).
- UI: ванильный HTML/CSS/JS, никаких CDN и сборщиков. Всё должно работать офлайн.
- Тексты: по делу, без маркетингового шума и без выдуманных цифр.

## Добавить своё приложение в каталог
Через лаунчер (Marketplace → «Добавить свой репозиторий») или через сайт.
Модерация проверяет: репозиторий существует, лицензия указана, есть сборки под ОС.
Предложить правку к чужой записи можно кнопкой «✎» — это отдельный пункт на проверку.

## Лицензия вклада
Отправляя PR, вы соглашаетесь на публикацию кода под MIT (см. LICENSE).
